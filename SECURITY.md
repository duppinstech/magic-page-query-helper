# Security policy

## Supported versions

Security updates are applied to the latest release in the default branch. Older versions may not receive backports unless the issue is severe and a fix is straightforward.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security-sensitive reports.

Instead, contact the maintainers privately with:

- A short description of the issue and its impact
- Steps to reproduce (or a proof of concept), if safe to share
- Affected versions or environments, if known

Use the contact options listed on the repository owner’s GitHub profile or project website. If you use GitHub’s private vulnerability reporting feature for this repository, that is also welcome.

## What to expect

- We aim to acknowledge receipt within a few business days
- We will work on a fix and coordinate disclosure; credit can be given in release notes if you wish

Thank you for helping keep users safe.
